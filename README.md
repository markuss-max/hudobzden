# 🐰💖🐻 Лапка & Пончик — Парный трекер калорий и веса

Уютное mobile-first веб-приложение для двоих (парень и девушка) в стиле «няшный минимализм». Работает без сборки (чистые ES-модули) — готово к деплою на **GitHub Pages** или **Vercel** за 1 минуту.

## ✨ Что умеет приложение
- **Парный дашборд («Сегодня»):** анимированное кольцо прогресса, батарейка партнёра (с поддержкой режима приватности 🔒), быстрые реакции 🔥 / 🍩 в реальном времени, авто-сброс в 00:00.
- **Стрик, «Копилка желаний» и «Заначка на выходные»:** общий счётчик дней в норме, шкала до награды и банк сэкономленных калорий (до 200 ккал/день) на выходные.
- **3 способа добавления еды (только калории, без БЖУ):**
  1. Умный ИИ-ввод через **Google Gemini API** (ключ вводится во вкладке «Профиль»).
  2. Избранное (быстрые карточки в один тап).
  3. Ручной ввод + копирование блюд партнёра в 1 клик.
- **«Общая кухня»:** общие блюда (суп, пицца, запеканка) с быстрым выбором порции (`1/4`, `1/2`, `100г`, `200г`) и автоматическим уменьшением остатка.
- **«Прогресс»:** график веса (`Chart.js`) с прогнозом даты цели, тепловая карта месяца и трекер воды.
- **«Профиль»:** калькулятор дефицита по Миффлину — Сан-Жеору, выбор аватара, режим приватности, настройка цели и API-ключей.

## 🚀 Быстрый старт (Демо-режим)
Откройте сайт через любой локальный сервер (например, `python -m http.server 8080`) или сразу после деплоя и нажмите **«Открыть Демо-режим 🐾»** — все функции можно протестировать без регистрации.

## ☁️ Настройка Supabase (для реальной синхронизации пары)
1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. Откройте **SQL Editor** в панели Supabase и выполните весь скрипт из файла [`supabase/schema.sql`](./supabase/schema.sql).
3. В **Authentication → Providers → Email** при желании отключите *Confirm email*, чтобы заходить сразу без подтверждения почты.
4. Скопируйте **Project URL** и **anon public key** (из *Project Settings → API*) и вставьте их на стартовом экране приложения (или пропишите в `src/config.js` в `DEFAULT_SUPABASE_URL` и `DEFAULT_SUPABASE_ANON_KEY`).
5. Один из партнёров нажимает **«Создать комнату пары»**, а второй вводит полученный 6-значный код!

## ✨ Настройка Google Gemini API (для умного ИИ-ввода)
1. Получите бесплатный API-ключ в [Google AI Studio](https://aistudio.google.com/apikey).
2. В приложении перейдите во вкладку **«Профиль» → «Google Gemini API Key»** и вставьте ключ (он хранится локально в вашем браузере).

## 🌐 Деплой на GitHub Pages или Vercel
- **GitHub Pages:** залейте репозиторий на GitHub → *Settings → Pages → Source: Deploy from a branch (`main` / `/root`)*. Файл `.nojekyll` уже добавлен.
- **Vercel:** импортируйте репозиторий на [vercel.com](https://vercel.com) → Framework Preset: **Other** → Deploy.
